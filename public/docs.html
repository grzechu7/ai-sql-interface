Jak to działa

Trzy kroki — od struktury bazy do gotowego zapytania.

1

Pokaż strukturę bazy

Skopiuj listę tabel i kolumn z własnej bazy i wklej ją w narzędziu. Rekordów nie potrzebujemy.

2

Zadaj pytanie zwykłym językiem

Na przykład: „Pokaż 10 największych klientów”.

3

Otrzymaj gotowe zapytanie SQL

Dostajesz zapytanie SELECT dopasowane do nazw Twoich tabel i kolumn.

Czym jest schemat bazy danych?

Schemat to „plan” bazy: jakie są tabele, jakie mają kolumny i jak się ze sobą łączą. To nie to samo co dane.

Potrzebujemy: struktura

  • nazwy tabel, np. klienci
  • nazwy i typy kolumn, np. imie, data_zamowienia

Nie potrzebujemy: dane

  • imiona i nazwiska klientów
  • kwoty, adresy, numery zamówień

Przykład: dwie tabele połączone relacją — jeden klient może mieć wiele zamówień.

klienci
idnumer klienta
nazwanazwa firmy
1 klient → wiele zamówień
(zamowienia.klient_id = klienci.id)
zamowienia
idnumer zamówienia
klient_idkto zamówił
kwotawartość

Nie musisz przesyłać rekordów z bazy — wystarczy sama struktura.

Jak przygotować schemat?

Wybierz swój silnik bazy danych i rozwiń instrukcję. W każdej: gdzie wejść, co skopiować i gdzie wkleić.

MySQL / MariaDB
  1. Otwórz phpMyAdmin (albo MySQL Workbench) i wybierz swoją bazę.
  2. Wejdź w zakładkę SQL.
  3. Wklej poniższe zapytanie i podmień twoja_baza na nazwę swojej bazy.
  4. Uruchom je i skopiuj wynik.
SELECT
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  IS_NULLABLE,
  COLUMN_KEY
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = 'twoja_baza'
ORDER BY TABLE_NAME, ORDINAL_POSITION;

Wynik zaznacz w całości (Ctrl+A), skopiuj (Ctrl+C) i wklej na stronie Wklej schemat.

Oracle
  1. Otwórz SQL Developer i połącz się z bazą.
  2. Otwórz okno Worksheet.
  3. Wklej zapytanie dla swoich tabel (poniżej) i uruchom je. Jeśli potrzebujesz innej schemy, użyj wariantu z OWNER.
  4. Skopiuj wynik.
SELECT
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  DATA_LENGTH,
  DATA_PRECISION,
  DATA_SCALE,
  NULLABLE
FROM USER_TAB_COLUMNS
ORDER BY TABLE_NAME, COLUMN_ID;

Oracle — konkretny OWNER

OWNER to nazwa schemy, zwykle wielkimi literami, np. HR. Sprawdzisz ją przez SELECT USER FROM dual; Podmień HR na swoją.

SELECT
  OWNER,
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  NULLABLE
FROM ALL_TAB_COLUMNS
WHERE OWNER = 'HR'
ORDER BY TABLE_NAME, COLUMN_ID;

Wynik zaznacz w całości (Ctrl+A), skopiuj (Ctrl+C) i wklej na stronie Wklej schemat.

PostgreSQL
  1. Otwórz pgAdmin (Query Tool) albo psql i połącz się z bazą.
  2. Wklej zapytanie. Jeśli tabele są w innej schemie niż public, podmień jej nazwę.
  3. Uruchom je i skopiuj wynik.
SELECT
  table_name,
  column_name,
  data_type,
  is_nullable
FROM information_schema.columns
WHERE table_schema = 'public'
ORDER BY table_name, ordinal_position;

Wynik zaznacz w całości (Ctrl+A), skopiuj (Ctrl+C) i wklej na stronie Wklej schemat.

SQL Server
  1. Otwórz SQL Server Management Studio i połącz się z bazą.
  2. Wybierz swoją bazę i kliknij New Query.
  3. Wklej zapytanie, uruchom je i skopiuj wynik.
SELECT
  TABLE_SCHEMA,
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  IS_NULLABLE
FROM INFORMATION_SCHEMA.COLUMNS
ORDER BY TABLE_SCHEMA, TABLE_NAME, ORDINAL_POSITION;

Wynik zaznacz w całości (Ctrl+A), skopiuj (Ctrl+C) i wklej na stronie Wklej schemat.

SQLite
  1. Otwórz plik bazy w DB Browser for SQLite (zakładka Execute SQL) albo w konsoli sqlite3.
  2. Pierwsze zapytanie zwraca listę tabel. Drugie (PRAGMA) pokazuje kolumny jednej tabeli — podmień twoja_tabela i powtórz dla każdej tabeli, której potrzebujesz.
  3. Skopiuj wyniki.
SELECT name AS table_name
FROM sqlite_master
WHERE type = 'table' AND name NOT LIKE 'sqlite_%'
ORDER BY name;

PRAGMA table_info('twoja_tabela');

Wynik zaznacz w całości (Ctrl+A), skopiuj (Ctrl+C) i wklej na stronie Wklej schemat.

Bezpieczeństwo

Co faktycznie robi narzędzie.

  • Nie musisz podłączać swojej bazy. Wystarczy wkleić strukturę (tabele i kolumny).
  • Tylko SELECT. Akceptujemy wyłącznie zapytania zaczynające się od SELECT — odczyt, bez zmian w danych.
  • LIMIT. Jeśli w zapytaniu nie ma limitu wierszy, serwer dopisuje LIMIT 100.
  • Wyniki nie są zapisywane na stałe. W trybie demo trafiają do Twojej przeglądarki. Zapisujemy tylko plik schematu, który sam wgrasz po zalogowaniu.
  • Co jest wysyłane do AI. Do wygenerowania zapytania serwer wysyła Twoje pytanie i strukturę schematu do dostawcy modelu AI (OpenAI).

Pełny opis: Bezpieczeństwo · Polityka prywatności.

FAQ

Czy potrzebuję wiedzy SQL?

Nie. Zadajesz pytanie po polsku, a narzędzie zwraca gotowe zapytanie. Wystarczy, że skopiujesz strukturę bazy według instrukcji wyżej.

Czy muszę zakładać konto?

Nie, żeby wygenerować SQL: demo i wklejanie schematu działają bez konta. Konto jest potrzebne tylko, by zapisać schemat na później.

Czy przekazuję AI swoje dane?

Nie przesyłasz rekordów z bazy. Do modelu AI trafia Twoje pytanie i struktura schematu (nazwy tabel i kolumn). Szczegóły: Bezpieczeństwo i Polityka prywatności.

Czy mogę korzystać z Oracle/MySQL?

Tak. Dla MySQL/MariaDB, Oracle, PostgreSQL, SQL Server i SQLite znajdziesz instrukcję wyżej.

Czy mogę zapisać swój schemat?

Tak — po zalogowaniu wgraj plik JSON na stronie Załaduj schemat, a przy kolejnych wizytach zostanie użyty automatycznie.
