Po co wgrywać schemat JSON?

AI-SQL-Chat mapuje nazwy tabel i kolumn z Twojego pliku schema.json, aby generować jedno poprawne zapytanie SELECT dokładnie pod tę strukturę. Dzięki temu odpowiedzi są trafne, a ryzyko błędu mniejsze. Schemat przygotujesz w kilka minut w oparciu o krótką instrukcję (MySQL/PostgreSQL/SQL Server/Oracle).

Jak to działa na tej stronie?

  1. Wgraj plik .json ze strukturą tabel/kolumn (poniżej).
  2. Wpisz prośbę po polsku — narzędzie zaproponuje jedno zapytanie SELECT.
  3. Skopiuj SQL i użyj w swoim narzędziu/BI lub przejdź do wersji demo.

Bezpieczeństwo

  • Filtrowanie anty-SQLi (blokada DDL/DML, OUTFILE/INFILE, SLEEP/BENCHMARK),
  • wymuszony LIMIT i tylko jedna instrukcja,
  • brak trwałego zapisu wyników (w przeglądarce),
  • szczegóły w sekcji Bezpieczeństwo.

Instrukcja (skrót)

Aplikacja generuje zapytania SQL na podstawie wgranego przez Ciebie pliku schema.json (mapa tabel i kolumn). Wpisujesz prośbę zwykłym językiem, a system zwraca jedno zapytanie SELECT zgodne ze schematem.

Nie masz jeszcze pliku? Skorzystaj z poradnika: schema → JSON.

FAQ — schemat JSON

Jak przygotować plik schema.json?

Użyj krótkich zapytań dla swojego silnika (MySQL/PostgreSQL/SQL Server/Oracle), a wynik wyeksportuj do JSON. Instrukcja: schema → JSON.

Czy wynik zapytania jest gdzieś zapisywany?

Nie. Wyniki nie są trwale zapisywane — przetwarzamy je wyłącznie w pamięci przeglądarki na czas działania.

Czy narzędzie wykonuje modyfikacje w bazie?

Nie. System generuje i dopuszcza wyłącznie jedno zapytanie SELECT (tylko odczyt), z wymuszonym LIMIT oraz filtrami anty-SQLi.
