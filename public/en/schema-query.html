Why upload a JSON schema?

AI-SQL-Chat maps the table and column names from your schema.json file to generate a single valid SELECT query exactly for that database structure. This makes the answers more accurate and reduces the risk of errors. You can prepare the schema in a few minutes based on the short guide (MySQL/PostgreSQL/SQL Server/Oracle).

How does this page work?

  1. Upload a .json file with your tables/columns structure (below).
  2. Type your request in natural language — the tool suggests a single SELECT query.
  3. Copy the SQL and use it in your BI / tools, or go to the demo version.

Security

  • Anti-SQLi filtering (blocks DDL/DML, OUTFILE/INFILE, SLEEP/BENCHMARK),
  • enforced LIMIT and a single statement only,
  • no persistent storage of results (browser only),
  • details in the Security section.

Short how-to

The app generates SQL queries based on the schema.json file you upload (map of tables and columns). You write a request in plain language and the system returns a single SELECT query that matches your schema.

Don’t have a file yet? Use the guide: schema → JSON.

FAQ — JSON schema

How do I prepare the schema.json file?

Use short SQL queries for your database engine (MySQL/PostgreSQL/SQL Server/Oracle) and export the result to JSON. See the guide: schema → JSON.

Is the query result stored anywhere?

No. Results are not stored persistently — we process them only in browser memory for the duration of handling the request.

Does the tool modify data in the database?

No. The system generates and allows only a single SELECT query (read-only), with enforced LIMIT and anti-SQLi filters.
