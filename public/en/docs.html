What is a database schema?

A schema is the “blueprint” of a database: which tables exist, what columns they have and how they connect. It is not the same as the data.

We need: structure

  • table names, e.g. customers
  • column names and types, e.g. first_name, order_date

We do not need: data

  • customer names
  • amounts, addresses, order numbers

Example: two tables linked by a relation — one customer can have many orders.

How to prepare a schema?

Pick your database engine and expand the guide. Each one says where to go, what to copy and where to paste it.

MySQL / MariaDB
  1. Open phpMyAdmin (or MySQL Workbench) and select your database.
  2. Go to the SQL tab.
  3. Paste the query below and replace twoja_baza with the name of your database.
  4. Run it and copy the result.
SELECT
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  IS_NULLABLE,
  COLUMN_KEY
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = 'twoja_baza'
ORDER BY TABLE_NAME, ORDINAL_POSITION;

Select the whole result (Ctrl+A), copy it (Ctrl+C) and paste it on the Paste schema page.

Oracle
  1. Open SQL Developer and connect to your database.
  2. Open a Worksheet window.
  3. Paste the query for your own tables (below) and run it. If you need a different schema, use the OWNER variant.
  4. Copy the result.
SELECT
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  DATA_LENGTH,
  DATA_PRECISION,
  DATA_SCALE,
  NULLABLE
FROM USER_TAB_COLUMNS
ORDER BY TABLE_NAME, COLUMN_ID;

Oracle — a specific OWNER

OWNER is the schema name, usually in capital letters, e.g. HR. You can check yours with SELECT USER FROM dual; Replace HR with your own.

SELECT
  OWNER,
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  NULLABLE
FROM ALL_TAB_COLUMNS
WHERE OWNER = 'HR'
ORDER BY TABLE_NAME, COLUMN_ID;

Select the whole result (Ctrl+A), copy it (Ctrl+C) and paste it on the Paste schema page.

PostgreSQL
  1. Open pgAdmin (Query Tool) or psql and connect to your database.
  2. Paste the query. If your tables are in a schema other than public, replace its name.
  3. Run it and copy the result.
SELECT
  table_name,
  column_name,
  data_type,
  is_nullable
FROM information_schema.columns
WHERE table_schema = 'public'
ORDER BY table_name, ordinal_position;

Select the whole result (Ctrl+A), copy it (Ctrl+C) and paste it on the Paste schema page.

SQL Server
  1. Open SQL Server Management Studio and connect to your database.
  2. Select your database and click New Query.
  3. Paste the query, run it and copy the result.
SELECT
  TABLE_SCHEMA,
  TABLE_NAME,
  COLUMN_NAME,
  DATA_TYPE,
  IS_NULLABLE
FROM INFORMATION_SCHEMA.COLUMNS
ORDER BY TABLE_SCHEMA, TABLE_NAME, ORDINAL_POSITION;

Select the whole result (Ctrl+A), copy it (Ctrl+C) and paste it on the Paste schema page.

SQLite
  1. Open the database file in DB Browser for SQLite (Execute SQL tab) or in the sqlite3 console.
  2. The first query returns the list of tables. The second (PRAGMA) shows the columns of one table — replace twoja_tabela and repeat for each table you need.
  3. Copy the results.
SELECT name AS table_name
FROM sqlite_master
WHERE type = 'table' AND name NOT LIKE 'sqlite_%'
ORDER BY name;

PRAGMA table_info('twoja_tabela');

Select the whole result (Ctrl+A), copy it (Ctrl+C) and paste it on the Paste schema page.

Security

What the tool actually does.

  • You do not have to connect your database. Just paste the structure (tables and columns).
  • SELECT only. We accept only queries that start with SELECT — read access, no changes to data.
  • LIMIT. If the query has no row limit, the server appends LIMIT 100.
  • Results are not stored permanently. In demo mode they go to your browser. We only store the schema file that you upload yourself after signing in.
  • What is sent to the AI. To generate the query, the server sends your question and the schema structure to the AI model provider (OpenAI).

FAQ

Do I need to know SQL?

No. You ask a question in plain language and the tool returns a ready query. You only need to copy your database structure following the guides above.

Do I need an account?

Not to generate SQL: the demo and schema pasting work without an account. An account is only needed to save a schema for later.

Do I hand my data to the AI?

You do not upload records from your database. The AI model receives your question and the schema structure (table and column names). Details: Security and Privacy Policy.

Can I use Oracle/MySQL?

Yes. You will find guides for MySQL/MariaDB, Oracle, PostgreSQL, SQL Server and SQLite above.

Can I save my schema?

Yes — after signing in, upload a JSON file on the Load schema page and it will be used automatically on later visits.
